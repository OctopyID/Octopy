This page acknowledges the technologies, libraries, and resources used to build this website. I believe in giving credit where it's due and celebrating the incredible work of the
open-source community and creators.

## 🚀 Technologies Used

- **[Astro](https://astro.build/)** — A modern framework for building fast static websites.
- **[Aria Theme](https://astro.build/themes/details/aria/)** — A starter theme for Astro, customized for this site.
- **[Vue 3](https://vuejs.org/)** — A progressive JavaScript framework for building user interfaces.
- **[lucide-vue-next](https://github.com/lucide-icons/lucide)** — Modern, open-source SVG icons.

## 📦 Development Tools

- **[Vite](https://vitejs.dev/)** — A fast and modern build tool.
- **[TailwindCSS](https://tailwindcss.com/)** — A utility-first CSS framework.
- **[Prettier](https://prettier.io/)** — An opinionated code formatter for consistent styling.
- **[ESLint](https://eslint.org/)** — A tool to identify and fix JavaScript issues.

## 📚 Libraries & Utilities

- **[Moment.js](https://momentjs.com/)** — A library for parsing, validating, and formatting dates.
- **[VueUse](https://vueuse.org/)** — Essential Vue Composition utilities.
- **[Fontsource](https://fontsource.org/)** — Open-source fonts like Geist Mono and Instrument Sans.

## 🌐 Hosting & Deployment

- **[Wrangler](https://developers.cloudflare.com/workers/wrangler/)** — A CLI tool for managing Cloudflare Workers.
- **[Cloudflare Pages](https://pages.cloudflare.com/)** — A platform for deploying static websites.

# Laravel Octane Boilerplate

A production-ready boilerplate for building high-performance APIs and microservices using Laravel Octane and Swoole.

## Features

- **Blazing Fast**: Powered by Swoole for persistent execution.
- **Dockerized**: Complete `docker-compose` setup for local development.
- **Pre-configured**: Includes Redis, PostgreSQL, and basic JWT auth templates.

## Usage

Clone the repository and run the setup script to instantly scaffold your high-concurrency Laravel environment.

# Nuxt 4 Starter

The ultimate starting point for modern, fast, and SEO-optimized web applications using the latest Nuxt 4 release and Tailwind CSS v4.

## Key Features

- **Tailwind v4 Setup**: Uses `@tailwindcss/vite` without the legacy Nuxt module.
- **Nuxt Content v3**: Ready for markdown-driven collections.
- **Oxlint**: Pre-configured Rust-based linter for Vue files.

This is the exact boilerplate used to build `octopy.dev`.
